# Presentation Kit — Click-a-thon 2026

Everything you need to prepare the final demo and presentation for the judges.

## Files in this folder

| File | Purpose |
|---|---|
| [SLIDE_TEMPLATE.md](SLIDE_TEMPLATE.md) | **The master deck outline** — slide-by-slide structure, what to say, what to show, timing cues |
| [DEMO_SCRIPT.md](DEMO_SCRIPT.md) | **Live demo run-sheet** — exact steps, commands, expected outputs, fallback plans |
| [TALKING_POINTS.md](TALKING_POINTS.md) | **Key messages & judge Q&A prep** — evaluation criteria mapped to our answers, anticipated questions |
| [SCREENSHOTS_CHECKLIST.md](SCREENSHOTS_CHECKLIST.md) | **Visual evidence checklist** — every screenshot/recording needed, with naming convention |
| [UNSEEN_INCIDENT_PLAN.md](UNSEEN_INCIDENT_PLAN.md) | **Unseen dataset playbook** — step-by-step plan for when the sealed data drops |

## Quick-start

1. Read `SLIDE_TEMPLATE.md` first — it's the backbone.
2. Use `DEMO_SCRIPT.md` to rehearse the live demo at least twice.
3. Fill `TALKING_POINTS.md` with final numbers once the sealed dataset is processed.
4. Capture everything in `SCREENSHOTS_CHECKLIST.md` as backup evidence.
5. Follow `UNSEEN_INCIDENT_PLAN.md` when the surprise data arrives.

## Time budget (adjust to actual allocation)

|---|---|

| Q&A | 2–3 min |
